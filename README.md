# Secret Blocks
**Like the Secret Rooms Mod but for Fabric!**

[![FabricAPI](https://img.shields.io/static/v1?label=modloader&message=fabric&color=brightgreen)](https://www.curseforge.com/minecraft/mc-mods/fabric-api)
![Mod Environment](https://img.shields.io/static/v1?label=environment&message=client%2Fserver&color=yellow)
[![License](https://img.shields.io/static/v1?label=licence&message=LGPL-3.0&color=blue)](./LICENSE)

Secret Blocks adds blocks that take the look of the blocks around them. Use them to build hidden rooms, secret doors, traps and redstone that nobody can see.

- Place a secret block against a wall, and it looks like that wall.
- Underneath, it works like the block it stands in for: a door still opens, a chest still holds items, a repeater still repeats.
- Tools let you change a block's look face by face, or see through every disguise.

![A villager steps on a hidden pressure plate and a door opens in a brick wall](https://raw.githubusercontent.com/wiki/calibergames/secret-blocks/images/secret-door-and-plate.gif)

Every block and tool is described, with pictures, in the **[wiki](https://github.com/calibergames/secret-blocks/wiki)**.

## Blocks

- **[Building blocks](https://github.com/calibergames/secret-blocks/wiki/Building-Blocks):** Dummy Block, Ghost Block, One Way Glass, Secret Stairs, Secret Slab, Secret Clamber
- **[Doors and trapdoors](https://github.com/calibergames/secret-blocks/wiki/Doors-and-Trapdoors):** Secret Door, Secret Iron Door, Secret Trapdoor, Secret Iron Trapdoor
- **[Buttons and levers](https://github.com/calibergames/secret-blocks/wiki/Buttons-and-Levers):** Secret Button, Secret Stone Button, Secret Lever, Torch Lever
- **[Pressure plates](https://github.com/calibergames/secret-blocks/wiki/Pressure-Plates):** Secret Pressure Plate, Secret Player Pressure Plate, Secret Light and Heavy Weighted Pressure Plates
- **[Secret redstone](https://github.com/calibergames/secret-blocks/wiki/Secret-Redstone):** Secret Redstone Dust, Secret Redstone Wire, Secret Repeater, Secret Comparator
- **[Sensors](https://github.com/calibergames/secret-blocks/wiki/Sensors):** Secret Observer, Secret Daylight Detector, Secret Sculk Sensor
- **[Containers](https://github.com/calibergames/secret-blocks/wiki/Containers):** Secret Chest, Secret Trapped Chest, Secret Dispenser, Secret Dropper, Secret Hopper
- **[Pistons and gates](https://github.com/calibergames/secret-blocks/wiki/Pistons-and-Gates):** Secret Piston, Secret Sticky Piston, Secret Gate

Most are crafted from their vanilla counterpart and a Dummy Block; see [Crafting](https://github.com/calibergames/secret-blocks/wiki/Crafting).

## Tools

- **Switch Probe and Rotator Probe:** copy a block's look onto one face of a secret block, or turn a face's texture.
- **Secret Goggles:** see which blocks are secret.
- **Builder's Goggles:** see the real block behind every disguise.
- **Camouflage Wand:** turn vanilla blocks into secret blocks and back.

More in [Tools](https://github.com/calibergames/secret-blocks/wiki/Tools).

## Requirements

- Minecraft 1.19.2
- Fabric Loader 0.14.21 or later
- [Fabric API](https://modrinth.com/mod/fabric-api)
- With Sodium, you also need [Indium](https://modrinth.com/mod/indium). See [Compatibility](https://github.com/calibergames/secret-blocks/wiki/Compatibility) for shader packs, connected textures and Carpet.
